# 大学入試日程管理ツール for Excel

Microsoft Excel上で、大学入試の出願期間・試験日・合格発表日・入学手続締切日を一覧管理し、年間カレンダーとして可視化するマクロ付きExcelブックです。

複数の大学・学部・学科・入試方式を1つのシートにまとめ、受験日程の重複や今後の予定を確認しやすくすることを目的に作成しました。

## 主な機能

* 大学・学部・学科・入試方式ごとの情報管理
* 出願開始日、出願締切日、試験日、合格発表日、入学手続締切日の登録
* 登録した日程の年間カレンダーへの反映
* 入試年度に応じた日付・曜日の更新
* うるう年を考慮したカレンダー表示
* 土曜日・日曜日の視認性を高めた表示
* 試験日コードによる複数試験日の管理
* 志望順、偏差値・共通テスト得点率、科目別配点の記録
* vbacを利用したVBAソースコードの抽出・Git管理

## 画面構成

シート左側に大学・入試情報を入力し、右側の年間カレンダーに日程を表示します。

入力した日程は、次の種類ごとに色と記号を変えて表示されます。

| 種類      | 表示内容        |
| ------- | ----------- |
| 出願開始日   | 出願開始を示す記号と色 |
| 出願締切日   | 出願締切を示す記号と色 |
| 試験日     | 試験日を示す記号と色  |
| 合格発表日   | 合格発表を示す記号と色 |
| 入学手続締切日 | 手続締切を示す記号と色 |

## 動作環境

* Windows
* デスクトップ版Microsoft Excel
* VBAマクロを実行できる環境
* `.xlsm`形式のファイルを開けるExcel

Excel Onlineや、VBAマクロに対応していない表計算ソフトでは正常に動作しません。

macOS版Excelでは、ブック自体を利用できる場合がありますが、vbacはWindows Script HostとExcelのCOM操作を利用するため、VBAソースの抽出・再構築にはWindows環境が必要です。

## 使用方法

### 1. Excelブックを開く

`bin/StudyChart.xlsm`をMicrosoft Excelで開きます。

セキュリティ警告が表示された場合は、ファイルの入手元と内容を確認したうえで、マクロを有効にしてください。

### 2. 入試年度を設定する

シート左下の入試年度欄である`E29`セルに、管理する年度を西暦4桁で入力します。

例：

```text
2027
```

入力後、シート左下の「更新」ボタンを押してください。

指定した年度に合わせて、年間カレンダーの日付と曜日が更新されます。

### 3. 入試情報を入力する

A列からS列に、大学ごとの情報を1行ずつ入力します。

| 列   | 入力内容         |
| --- | ------------ |
| A   | 大学名          |
| B   | 学部           |
| C   | 学科           |
| D   | 入試方式         |
| E   | 志望順          |
| F   | 出願開始日        |
| G   | 出願締切日        |
| H   | 試験日          |
| I   | 合格発表日        |
| J   | 入学手続締切日      |
| K   | 試験日コード       |
| L   | 偏差値・共通テスト得点率 |
| M～S | 科目別配点        |

日付は、Excelが日付として認識できる形式で入力してください。

### 4. 年間カレンダーへ反映する

必要な情報を入力した後、シート左下の「更新」ボタンを押します。

A列からS列へ入力した日程が、T列以降の年間カレンダーへ反映されます。

更新処理では、既存のカレンダー表示を一度クリアした後、各行に登録された日程を再描画します。

## 試験日コードについて

1つの入試方式に複数の試験日が設定されている場合は、「試験日コード」を使用します。

1. 対象となる大学のK列に、`1`から`5`のいずれかを入力します。
2. シート左下にある同じ番号の試験日コード欄へ、複数の試験日を入力します。
3. 「更新」ボタンを押します。

指定したコードに登録された複数の日付が、対象行の試験日としてカレンダーへ反映されます。

## 入力時の注意事項

* 日付は文字列ではなく、Excelの日付データとして入力してください。
* 入試年度を変更した場合は、再度「更新」ボタンを押してください。
* マクロを無効にした状態では更新処理を実行できません。
* カレンダーへの反映対象は、現在のVBA実装では12月から翌年3月までです。
* 大学情報の入力対象行は、現在のVBA実装では4行目から27行目までです。
* シートの行・列構成を変更すると、マクロが正しく動作しなくなる可能性があります。
* ファイルを大きく編集する前に、バックアップを作成してください。
* 実際の出願時には、各大学が公開する最新の募集要項を必ず確認してください。

## 開発・保守

本プロジェクトでは、Excelブック内のVBAコードをテキストファイルとして管理するため、Ariawaseの`vbac.wsf`を使用しています。

Excelブックはバイナリファイルであるため、Git上ではVBAコードの変更差分を確認しにくいという問題があります。vbacでVBAモジュールを`src`ディレクトリへ抽出することで、`.bas`などのテキストファイルとして差分を確認できます。

### vbacの準備

Ariawaseから`vbac.wsf`を取得し、リポジトリのルートディレクトリへ配置します。

```text
Excel_Exam-master/
├─ vbac.wsf
├─ bin/
├─ src/
└─ Readme.md
```

このリポジトリでは`vbac.wsf`をGit管理対象外としているため、利用する環境ごとに別途用意してください。

### Excelの事前設定

vbacからVBAプロジェクトへアクセスできるように、Excelで次の設定を有効にします。

1. Excelの「ファイル」を開く
2. 「オプション」を開く
3. 「トラストセンター」を選択する
4. 「トラストセンターの設定」を開く
5. 「マクロの設定」を選択する
6. 「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」を有効にする

この設定を有効にすると、外部プログラムからVBAプロジェクトへアクセスできるようになります。信頼できるファイルと環境でのみ使用してください。

### VBAソースを抽出する

Excelで`bin/StudyChart.xlsm`を編集した後、Excelブックを保存して閉じます。

その後、コマンドプロンプトまたはPowerShellでリポジトリのルートディレクトリへ移動し、次のコマンドを実行します。

```powershell
cscript //nologo vbac.wsf decombine
```

vbacは既定で`bin`ディレクトリ内のマクロ有効Officeファイルを読み込み、VBAソースを`src`ディレクトリへ出力します。

抽出後は、次の両方の変更内容を確認します。

* `bin/StudyChart.xlsm`
* `src/StudyChart.xlsm/`以下のVBAソース

VBAコードの変更内容は、主に`src`以下のテキスト差分で確認します。

### VBAソースからブックを再構築する

`src`ディレクトリのVBAソースを`bin/StudyChart.xlsm`へ反映する場合は、次のコマンドを実行します。

```powershell
cscript //nologo vbac.wsf combine
```

実行後はExcelブックを開き、正常に再構築されていることを確認してください。

### 保守時の確認項目

VBAコードを変更または再構築した後は、次の項目を確認します。

* `StudyChart.xlsm`がエラーなく開けること
* VBAエディターでコンパイルエラーが発生しないこと
* 「更新」ボタンを実行できること
* 入試年度に応じて曜日が更新されること
* 出願開始日から入学手続締切日までが正しい位置に表示されること
* 試験日コードに設定した複数日程が反映されること
* うるう年の2月29日が正しく表示されること
* 不要な一時ファイルがGitの変更対象に含まれていないこと

### 推奨する変更手順

1. 作業前にGitの作業ツリーがクリーンであることを確認する
2. `bin/StudyChart.xlsm`をExcelで開く
3. VBAまたはシートを編集する
4. Excelブックを保存して閉じる
5. `vbac.wsf decombine`を実行する
6. `src`以下の差分を確認する
7. Excelブックを再度開いて動作確認する
8. `.xlsm`とVBAソースを同じコミットへ含める

`.xlsm`にはセルの値、数式、書式、図形、ボタン配置など、VBAソースだけでは管理できない情報も含まれます。そのため、本プロジェクトでは`bin/StudyChart.xlsm`と`src`以下のVBAソースを併せて管理します。

## 想定用途

* 受験予定校の日程整理
* 出願期間の重複確認
* 試験日の重複確認
* 合格発表日の一覧化
* 入学手続締切日の見落とし防止
* 志望校ごとの難易度や科目別配点の比較

## 現在の制限事項

* 1つのシート上での利用を前提としています。
* 日程の表示範囲は12月から翌年3月までです。
* 大学情報の入力行数は、現在のマクロでは4行目から27行目までです。
* シート内のセル位置を直接参照しているため、レイアウト変更時にはVBAコードの修正が必要です。
* 入力値の詳細なバリデーションやエラーメッセージは実装していません。
* 大学の入試情報を自動取得する機能はありません。
* Excel Onlineには対応していません。
